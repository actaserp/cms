    통장기재내용

    납부자 통장에 찍히는 문구입니다. 총 16바이트(한글·전각 2, 영숫자 1)까지 들어갑니다.
    앞부분 (0바이트)는 결제원 신고 문구라 바꿀 수 없고, 남는 0바이트에만 입력할 수 있어요.
    · 은행에 따라 뒷부분이 표시되지 않을 수 있습니다.
    숫자·영문은 자동으로 전각(８)으로 바뀝니다. 반각을 쓰면 은행에서 거부됩니다(0087).
    사용 0 / 16 바이트
    16바이트를 초과했습니다. 문구를 줄여주세요.

    엑셀 업로드

    · 청구번호 있음 → 수정 (대기 상태만): 청구금액 · 출금일자 · 메모만 반영됩니다.
    · 청구번호 없음 → 신규: 납부자명 · 청구금액 · 출금일자 필수. 납부자번호는 선택.
    · 계좌·은행·예금주는 엑셀로 수정할 수 없어요(회원 등록 계좌 기준). 신규 건 계좌는 자동으로 채워집니다.
    · 동명이인이면 해당 회원 수만큼 각각 청구가 생성됩니다. 특정하려면 납부자번호를 함께 넣으세요.
    · 양식 파일 받기 후 작성하면 편해요.
